# ビルドと配布

開発には .NET 10 SDK が必要。コマンドはプロジェクトのルート（`CreateQRcode.csproj` があるディレクトリ）で実行する。

## 開発用の起動

```powershell
dotnet run
```

これは実行環境に .NET 10 の Windows デスクトップランタイムがある前提のビルド。成果物は `bin\Debug\net10.0-windows\CreateQRcode.exe`。

Release ビルドは次のとおり。

```powershell
dotnet build -c Release
```

成果物は `bin\Release\net10.0-windows\CreateQRcode.exe`。

## ポータブル版

.NET をインストールしていない 64 ビット Windows でも動く、単一ファイルの自己完結版。

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -p:DebugSymbols=false -o publish/win-x64
```

出力は `publish\win-x64\CreateQRcode.exe`。`publish/` は `.gitignore` に含まれ、リポジトリには入らない。

WPF はトリミングすると動きが壊れることがある。ポータブル版ではトリミングしない。
